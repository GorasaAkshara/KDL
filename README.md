# HealthTrack - Personal Health Management System

HealthTrack is a comprehensive web application designed to help individuals manage their health metrics, appointments, and receive personalized health advice through an AI companion.

## Features

- **Health Metrics Tracking**
  - Track blood pressure, temperature, heart rate, weight, and blood sugar
  - Visualize health data with interactive charts
  - Set and monitor health goals

- **Appointment Management**
  - Schedule and manage medical appointments
  - Receive appointment reminders
  - View appointment history

- **AI Health Companion**
  - Chat with an AI assistant for health-related queries
  - Receive personalized health advice
  - Get information about common health concerns

- **Medication Management**
  - Track medication schedules
  - Set medication reminders
  - View medication history

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```

2. Navigate to the project directory:
   ```bash
   cd healthtrack
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm start
   ```

5. Open your browser and navigate to `http://localhost:3000`

## Dependencies

- Chart.js for data visualization
- Font Awesome for icons
- Modern CSS features (CSS Variables, Grid, Flexbox)

## Browser Support

The application is compatible with:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Security and Privacy

- All health data is stored locally in the browser
- No personal data is shared with third parties
- Regular security updates and patches
